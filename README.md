# 🕷️ Web Scraping

A collection of web-scraping projects built using Python, Requests, and BeautifulSoup to extract, process, and store data from websites.

## 🚀 Projects

| Project | Description | Technologies |
|---|---|---|
| 🎬 [Movie Scraper](./Movie-Scraper) | Scrapes a ranked list of movies from an archived Empire Online page and saves the results to a text file. | Python, Requests, BeautifulSoup |
| 🎵 [Billboard Spotify](./Billboard-Spotify) | Scrapes Billboard's Hot 100 chart for a selected date and creates a private Spotify playlist containing the available songs. | Python, Requests, BeautifulSoup, Spotipy, Spotify API |

## 🛠️ Technologies

- Python
- Requests
- BeautifulSoup
- Spotipy
- Spotify Web API
- Web Scraping
- HTML Parsing
- API Integration
